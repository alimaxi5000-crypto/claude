What this build can and cannot do

  • Runs FiveM-style Lua resources (fxmanifest, events, exports, commands, threads)
  • Connects a headless client to a Jays test server over its own protocol
  • Queries server info in the FXServer getinfo / info.json format
  • Does not start or inject into GTA V; no game natives, entities or sync
  • Cannot join FiveM (FXServer) game sessions
